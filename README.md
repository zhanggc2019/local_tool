# 本地工具箱

基于 Go、Wails 3 和 TypeScript 的 Windows 本地工具箱。当前提供 **PDF 转图片**、**PDF 处理（合并/拆分/压缩）**、**PDF 页面管理**、**PDF 加水印**、**PDF 加密/解密**、**PDF 提取文本**、**图片转 PDF**、**证件照制作**、**人像抠图**、**图片去水印**、**图片加水印**、**长图拼接**、**图片格式转换**、**视频压缩**、**视频剪辑**、**GIF 制作**、**视频截图**、**视频格式转换**、**视频合并**、**视频信息**、**视频倍速**、**视频转音频**、**音频剪辑**、**音量标准化**、**音频降噪**、**网址二维码**和**端口占用查询**；左侧菜单按 PDF、图片、音视频和实用工具分组，可点类别标题折叠/展开，也可一键全部折叠，展开状态会在下次启动时恢复，各工具有独立的界面、处理逻辑和本机服务，便于继续扩展。

## PDF 转图片

- 选择 PDF，预览首页。
- 图片宽度可选 900、1400、2000 像素；默认 1400 像素。
- 多页 PDF 默认纵向合成一张长图，也可按页导出多张。
- JPG（默认，质量 82%）或 PNG；导出后可打开输出文件夹。
- PDF.js、字体资源和页面映射表均随应用打包，转换不需要网络或外部 PDF 命令。
- 可勾选批量模式，一次选择最多 50 个 PDF，逐个转换；图片默认保存在每个原 PDF 所在文件夹。

为了防止意外生成超大图片，单张图片最多 2000 万像素，最长边不超过 16000 像素；合成长图时会自动降低宽度。若页面太多，无法在可读宽度下合成，会提示改用按页导出。输入 PDF 上限为 100 MB、500 页。

## PDF 合并/拆分/压缩

- 合并：选择多个 PDF，调整顺序并保存为一个新文件；默认存放在排序后首个 PDF 所在文件夹。
- 拆分：可批量选择 PDF，指定每份页数；每个 PDF 的输出放在其原文件夹下的新子文件夹中。
- 压缩：可批量优化 PDF 的结构与重复资源，新文件默认保存在各自原文件夹，并显示实际节省的体积。已优化的 PDF 可能不会变小。
- 全程在本机处理，源文件不会被修改。PDF 操作使用 pdfcpu，无需安装外部命令。

## PDF 页面管理

- 选择一个 PDF，输入页码表达式：支持 `1`、`1-3`、`3-`、`-2`、`偶数页`、`奇数页`、`全部`，中英文逗号均可分隔，重复页码自动去重排序。
- 旋转：90°、180° 或 270° 顺时针；页码留空表示全部页面。
- 删除：删除所选页面后另存，不能删除全部页面。
- 提取：为每个所选页面生成单独的 PDF，保存在原文件夹下的“原文件名_提取页”新文件夹中；同名文件夹自动追加序号。
- 页码超出 PDF 页数会明确报错；所有结果均不修改源文件。

## PDF 加水印

- 选择一个 PDF，在每个页面居中叠加半透明文字水印，字号 12–96 pt、不透明度 5–100%、旋转 -90–90°、灰/红/蓝/黑四色。
- 默认绘制在页面内容下方；勾选后显示在内容上方。
- 中文水印会在首次使用时从系统字体目录安装一个 CJK 字体（黑体、等线等）到本机缓存，并以子集嵌入 PDF；若系统缺少可用中文字体，会提示改用英文水印。英文水印使用 PDF 标准 Helvetica 字体。
- 水印输出保存在原文件夹，命名为“原文件名_水印.pdf”；页面数不变，源文件不修改。

## PDF 加密/解密

- 选择一个 PDF，设置 4–64 字符的打开密码；所有者密码可留空（默认与打开密码相同），可分别允许或禁止打印、复制文本。
- 使用 AES-256 加密，输出保存在原文件夹，命名为“原文件名_加密.pdf”。
- 解密需要输入当前密码（打开密码或所有者密码均可）；成功后输出“原文件名_解密.pdf”。
- 已加密的 PDF 会被识别并显示“已加密”标记；重新加密前需要先解密。
- 请妥善保管密码：密码丢失后无法恢复文件内容。

## PDF 提取文本

- 选择一个 PDF（1–500 页，100 MB 以内），使用随应用打包的 PDF.js 在本机解析文本层。
- 先显示预览与字符数统计，确认后再保存为 UTF-8（带 BOM）的 TXT，默认位于原文件夹，命名为“原文件名_文本.txt”。
- 扫描件或纯图片 PDF 没有文本层，会提示无法提取；加密 PDF 会提示先解密。

## 图片转 PDF

- 选择 JPG、PNG 或 WebP 图片（每张 20 MB 以内），一次最多 50 张，按选择顺序合成一个 PDF。
- 列表中可逐张上移/下移调整页面顺序。
- 页面布局二选一：适应 A4 页面（等比缩放并居中，默认）或保持图片原始尺寸（每页与图片同比例）。
- 输出 PDF 默认保存在第一张图片所在文件夹，命名为“原文件名_转PDF.pdf”；源图片不会修改。
- 全程使用 pdfcpu 在本机处理。注意：手机照片的 EXIF 旋转方向按原始像素写入，不会自动纠正。

## 证件照制作

- 导入 20 MB 以内的 JPG、PNG 或 WebP 正面人像；在本机识别人像并替换背景。
- 选择 1 寸（25 × 35 mm，295 × 413 px）或 2 寸（35 × 49 mm，413 × 579 px）。
- 选择蓝底、红底或白底，拖动预览调整位置，通过滑块缩放，同时保存带 300 DPI 标记的 JPG 与 PNG 两个文件。
- 人像模型和运行所需的 WASM 文件随应用打包，处理照片不需要网络。复杂头发、透明物件或与人像颜色接近的背景可能影响抠图边缘，请保存前检查预览。
- 可勾选批量模式，一次选择最多 50 张照片。所选尺寸、底色、缩放和位置应用到全部照片，结果默认保存在每张原照片所在文件夹。

不同证件和受理机构可能要求其他尺寸、像素、底色或头部占比；提交前请按具体要求核对。

## 人像抠图

- 选择 20 MB 以内的 JPG、PNG 或 WebP 含人物图片；本机识别人像并移除背景。
- 背景可选透明、白底、蓝底、红底或绿底；透明背景自动使用 PNG，纯色背景可选 PNG 或 JPG。
- 单张模式选择后立即识别并预览（透明背景显示棋盘格），可随时切换背景对比效果。
- 批量模式一次选择最多 50 张，逐张识别并保存，结果默认保存在各原图片所在文件夹。
- 人像分割模型与证件照工具共用同一份打包资源。复杂头发、透明物件或与人像颜色接近的背景可能影响边缘，请检查预览。

## 图片加水印

- 选择 JPG、PNG 或 WebP 图片，批量模式一次最多 50 张；同一设置应用到全部图片。
- 文字水印支持九宫格定位（左上到右下）或整图平铺，字号 12–160 px、不透明度 5–100%、白/黑/红/蓝四色。
- 中文使用系统字体渲染；首张图片显示实时预览，便于确认位置与透明度。
- 输出 PNG（保留透明）或 JPG（白色背景），默认保存在各原图片所在文件夹，命名为“原文件名_水印”，源图片不修改。

## 长图拼接

- 选择 2–50 张图片，按列表顺序从上到下拼接，可逐张上移/下移调整顺序。
- 统一宽度后等比缩放：可选原图最大宽度、1080、750 或 640 px；图片间距 0/8/16 px（白色分隔）。
- 安全上限：长边不超过 16000 px、总像素不超过 3200 万，超出时会提示减少图片或降低宽度。
- 输出 JPG 或 PNG，默认保存在第一张图片所在文件夹，命名为“原文件名_长图”。

## 图片去水印

- 导入 20 MB 以内的 JPG、PNG 或 WebP 图片，最多 1600 万像素。
- 调整画笔，在水印上涂选；可撤销或清空涂选，并按住按钮查看原图。
- 点击“修复选区”后，可继续处理其他区域，最后保存为 PNG 或 JPG。
- 修复在本机的后台线程完成，不需要账号、密钥或外部服务。它适合小块水印；复杂纹理、大面积遮挡可能留下痕迹。
- 可勾选批量模式，一次选择最多 50 张图片；首张图的涂选区域按图片尺寸比例应用于全部图片，修复结果默认保存在各自原文件夹。批量图片适合水印位置一致的素材。

## 网址二维码

- 输入 HTTP 或 HTTPS 网址；省略协议时自动补全 HTTPS。
- 选择 512、1024 或 2048 像素，生成带标准留白的二维码并保存为 PNG。
- 二维码在本机生成，不会请求输入的网址；分享前建议用手机扫码核对。

## 端口占用（仅 Windows）

- 输入 1–65535 的本地端口号，查询 TCP/UDP 占用进程、PID、程序路径和本地连接。
- 可直接结束占用进程。操作前会再次核对端口、PID 和进程启动标识；系统关键进程与工具箱自身不可结束。
- 结束进程会立即关闭程序，未保存的数据可能丢失；权限不足时会提示以管理员身份运行。

## 视频剪辑

- 选择 MP4、MOV、MKV、AVI、WebM、M4V 或 WMV 视频；批量模式一次最多 50 个，起止时间应用到全部所选视频。
- 时间支持“90”（秒）或“1:30”“1:02:03”格式；结束时间超出视频时长的视频会单独失败，其余继续处理。
- 快速剪辑：流拷贝、不重新编码、秒级完成，但切点会吸附到关键帧，实际起止可能偏移几秒；输出保持原容器格式。
- 精确剪辑：重新编码为 H.264 MP4（音频 128 kbps AAC），帧级准确，耗时更长。
- 结果默认保存在原视频所在文件夹，命名为“原文件名_剪辑”，源视频不修改。

## GIF 制作

- 选择一个视频，设置片段起止（最长 60 秒），可调画面宽度（320/480/640）与帧率（10/15/24）。
- 使用 palettegen/paletteuse 调色板优化与 lanczos 缩放，输出无限循环 GIF。
- 结果默认保存在原视频所在文件夹，命名为“原文件名_GIF.gif”。

## 视频截图

- 选择一个视频，两种方式：指定时间点截一帧（适合封面），或把整段视频均分成 4/6/9/12 张。
- 均分模式自动避开片头片尾；输出 JPG，编号为“原文件名_截图_1.jpg”等，单帧为“原文件名_截图.jpg”。
- 时间超出视频时长会提示具体时长，不会静默截取错误画面。

## 视频压缩

- 选择 MP4、MOV、MKV、AVI、WebM、M4V 或 WMV 视频（单个 4 GB 以内）；批量模式一次最多 50 个。
- 压缩强度按目标体积选择：约一半（画质优先）、约三分之一（平衡）、约五分之一（体积优先）。
- 按目标体积自动计算视频码率，重新编码为 H.264（OpenH264，随 FFmpeg LGPL 构建打包）+ 96 kbps AAC 的 MP4；保持原有画面尺寸。
- 结果默认保存在原视频所在文件夹，命名为“原文件名_压缩.mp4”，源文件不修改；完成后显示前后体积与节省比例。
- 已高效压缩或极小的视频可能不会变小，结果中会如实标注“未能减小体积”。一个视频失败不影响其余视频。

## 音频降噪

- 选择 40 MB 以内的 WAV、MP3 或 M4A 人声录音，最长 10 分钟。音频由本机 WebView 解码并转换为 48 kHz，格式能否解码取决于 WebView2 的编解码器支持。
- 使用随应用打包的 DeepFilterNet3 CPU 模型离线降噪；强度可在 0–100 之间调整，也可选择安静室内、办公室、户外街道、强风噪声的建议值。强度映射到模型的衰减限制，高于等于 85 时开启后置滤波。建议值并不保证特定录音的效果，请试听后调整。
- 提供原音与降噪结果播放器，切换试听时会尽量保持播放位置；分别显示格式、采样率、时长、声道和文件大小。输出可选 48 kHz WAV（默认）或 192 kbps MP3，结果保存在原音频所在文件夹，源文件不修改。
- 主要面向单人讲话录音。对音乐、混响、其他人声和极重噪声不保证有效，建议试听后选择合适强度。

## 图片格式转换

- 选择 JPG、PNG 或 WebP 图片（每张 20 MB 以内），批量模式一次最多 50 张。
- 输出 JPG 或 PNG：JPG 可调质量（40–100），PNG 无损；最大边长可选原尺寸、2000、1400 或 1000 像素，长边超出时等比缩小。
- 透明图片转 JPG 时以白色填充背景；重新编码会移除 EXIF 等元数据。
- 结果默认保存在各图片所在文件夹，命名为“原文件名_转换.jpg/png”，并显示前后体积与尺寸。

## 视频格式转换

- 选择 MP4、MOV、MKV、AVI、WebM 等视频，批量模式一次最多 50 个，目标容器为 MP4、MKV 或 WebM。
- MP4：源文件本身是 MP4 时直接复制流并加 faststart；其他来源转码为 H.264 + AAC，兼容性最好。
- MKV：直接复制音视频流，最快且无损。
- WebM：转码为 VP9 + Opus，体积小但耗时较长。
- 所有模式都会移除字幕与数据流；结果保存在原视频所在文件夹，命名为“原文件名_转换.<容器>”。

## 视频合并

- 选择至少 2 个、最多 50 个视频，按列表顺序拼接，可逐段上移/下移调整。
- 快速合并：直接复制流、不重新编码，要求各视频编码与分辨率一致；不一致时会失败并提示改用兼容合并。
- 兼容合并：以第一个视频的分辨率与帧率为准，统一缩放并居中填充，重新编码为 H.264 + AAC；缺少音轨的视频自动补静音。
- 输出默认保存在排序后首个视频所在文件夹，命名为“原文件名_合并”；快速合并沿用原容器（不支持的容器回退为 MKV），兼容合并输出 MP4。

## 视频信息

- 选择一个视频，显示容器格式、时长、文件大小、总码率、视频编码、分辨率、帧率、视频码率、音频编码、采样率、声道与音频码率。
- 信息由随应用打包的 FFmpeg 在本机探测，不会上传文件。

## 视频倍速

- 选择视频，速度可选 0.5×、0.75×、1.25×、1.5×、2×、3×、4×；批量模式一次最多 50 个。
- 视频用 `setpts` 调整时间戳，音频用 `atempo` 保持音调不变（超出 0.5–2 范围时自动串联滤镜）。
- 输出为 H.264 + AAC 的 MP4，默认位于原视频所在文件夹，命名为“原文件名_倍速.mp4”。

## 音频剪辑

- 选择 MP3、WAV、M4A、AAC、FLAC 或 OGG 音频，批量模式一次最多 50 个，起止时间应用到全部文件。
- 时间格式为“90”（秒）或“1:30”“1:02:03”；结束时间超出音频时长会单独失败，其余继续。
- 快速剪辑直接复制流、保持原格式；精确剪辑重新编码为 192 kbps MP3。
- 结果默认保存在原音频所在文件夹，命名为“原文件名_剪辑”。

## 音量标准化

- 选择音频文件（单次最多 50 个），统一响度到 -16 LUFS、峰值限制 -1.5 dBTP，适合播客与录音。
- 输出 MP3（192 kbps）或 WAV（48 kHz PCM），默认保存在原音频所在文件夹，命名为“原文件名_标准化”。
- 使用 FFmpeg `loudnorm` 单遍处理；音乐、电影原声等宽动态素材可能不适合该目标，建议试听。

## 视频转音频

- 选择 MP4、MOV、MKV、AVI、WebM、M4V 或 WMV 视频；勾选批量模式可一次选择最多 50 个视频，每个文件上限为 4 GB。
- 提取视频的首条音轨，默认输出 192 kbps MP3，也可输出 48 kHz、16 位 PCM WAV。结果默认保存在各源视频所在文件夹，源文件不会被修改。
- 批量任务逐个处理，一个视频没有音轨或处理失败时会显示原因，其余视频继续提取。
- 使用随应用打包的 Windows FFmpeg LGPL 版本；首次使用会将转换程序解压到本机用户缓存，后续提取无需网络，也无需另行安装 FFmpeg。

## 运行与构建（Windows PowerShell）

要求：Go 1.26+、Node.js/npm、WebView2 Runtime。首次安装 Wails 3 CLI：

```powershell
go install github.com/wailsapp/wails/v3/cmd/wails3@v3.0.0
$env:Path = "$(go env GOPATH)\bin;$env:Path"
```

在项目根目录执行：

```powershell
cd frontend
npm ci
cd ..
wails3 dev
```

生成 Windows 可执行文件：

```powershell
wails3 build
```

默认输出位于 `bin/pdf-desktop.exe`。如果正在运行这个文件，可用 `wails3 build APP_NAME=paperdesk` 生成 `bin/paperdesk.exe`。CLI 若不在 `PATH` 中，请按上面的命令把 Go 的 `bin` 目录加入当前 PowerShell 会话。

## 测试

```powershell
go test ./...
cd frontend
npm test
npm run build
```

`testdata/sample-2pages.pdf` 是一个仅用于验证的两页样例，`testdata/sample-video.mp4` 用于视频提取、压缩、剪辑、GIF、截图、格式转换、合并、倍速与信息探测的真机测试；音频相关测试会在临时目录生成正弦波文件。媒体测试会解压并运行随应用打包的 FFmpeg（仅 Windows 构建标签下执行）。

以下内容无法在自动化测试中覆盖，已在代码与文档中标记，需要运行应用人工验证：

- **原生文件对话框**：`ChooseVideos`、`ChooseImages`、`ChooseFiles` 等需要运行中的桌面窗口；测试仅覆盖无窗口时的报错路径。
- **人像分割与画布合成**：MediaPipe 模型推理、`createImageBitmap`、`toDataURL` 需要真实 WebView；单元测试仅覆盖蒙版 alpha 曲线、背景与格式规则等纯函数。抠图边缘质量依赖真实照片，需人工检查预览。
- **界面布局与交互**：侧栏分组导航、抠图预览棋盘格、排序列表按钮、时间码输入校验的即时反馈、水印滑杆与色块等视觉表现需运行 `wails3 dev` 人工确认。
- **画布水印与长图**：文字定位/平铺和长图拼接依赖真实 WebView 的 Canvas 与系统字体；单元测试覆盖锚点坐标、平铺覆盖、尺寸规划与安全上限，最终画面需人工检查。
- **快速剪辑的切点精度**：依赖源视频关键帧分布，自动化测试只验证输出可解析与时长参数；实际偏移需用真实素材人工比对。
- **快速视频合并的兼容性**：复制流合并只在编码参数一致时成功；测试使用两个相同来源验证成功路径，真实素材的不兼容失败路径只验证错误提示文案。
- **中文字体水印的实际字形**：测试验证 Form XObject 使用嵌入的 Type0 CID 字体并包含文字绘制指令；系统缺少中文字体时该测试会自动跳过。字形是否正确需人工打开 PDF 检查。
- **PDF 文本提取的版式还原**：测试覆盖文本片段拼接、分页与预览截断；实际排版（列、表格顺序）依赖 PDF.js 的读取顺序，需用真实文档人工核对。
- **音频听感**：倍速的音调保持、音量标准化的主观效果需人工试听；测试只验证时长、响度数值与文件可解析。

## 目录结构

- `main.go`：唯一入口，注册各工具服务并创建窗口。
- `internal/app/`：全部工具服务的实现与测试（单包，文件按 PDF、图片、音视频前缀命名）。
- `internal/tools/`：可独立测试的纯 Go 逻辑，例如 `pdfexport`、`photoexport`。
- `internal/imagefile/`：图片与文本共用的原子写入工具。
- `internal/app/third_party/`：随应用打包的 FFmpeg 与 DeepFilterNet 资源（`go:embed` 要求位于包目录内）。
- `frontend/src/tools/`：各工具的界面与浏览器端处理逻辑。

## 扩展新工具

- 在 `frontend/src/tools/` 下建立新工具目录，放入界面与处理逻辑。
- 在 `frontend/src/tools.ts` 注册入口（含 `category` 分组），并在 `frontend/src/main.ts` 的 `TOOL_VIEWS` 接入该工具的界面。
- 在 `internal/app/` 增加 Wails 服务文件（文件名建议按领域加前缀，如 `pdf_*.go`、`image_*.go`、`video_*.go`、`audio_*.go`），并在 `main.go` 的 `Services` 中注册 `app.NewXxxService()`。
- 可独立测试、无 Wails 依赖的逻辑放到 `internal/tools/`，由服务层调用；第三方二进制资源放在 `internal/app/third_party/`。
- 多个工具共用的模型或运行时放在 `frontend/src/tools/shared/`（如人像分割器）或 `internal/app/` 的共享文件（如 FFmpeg 运行时），避免重复加载。
- 保持浏览器处理模块与 Go 文件服务之间的接口明确；不要让一个工具直接修改另一工具的会话状态。

PDF 工具由 `frontend/src/tools/pdf-image/`（渲染、尺寸规划、界面）和 `internal/tools/pdfexport/`、`internal/app/pdf_service.go`（校验与保存）组成。证件照工具由 `frontend/src/tools/id-photo/`（人像识别、构图、界面）和 `internal/tools/photoexport/`、`internal/app/photo_service.go`（尺寸校验、DPI 标记与保存）组成。两者共用 `internal/imagefile/` 的原子写入逻辑。PDF 每次导出使用独立任务标识，按页文件不会覆盖已有同名文件。
